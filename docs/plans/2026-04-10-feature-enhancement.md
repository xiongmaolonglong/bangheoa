# 功能完善优化方案

## 当前问题汇总

| 模块 | 问题 | 优先级 |
|------|------|--------|
| 订单列表 | 右侧面积统计写死为0，缺少真实数据 | 高 |
| 订单列表 | 缺少批量导出功能 | 中 |
| 订单详情 | 操作日志默认折叠，用户可能忽略 | 中 |
| 审核中心 | 缺少批量审核功能 | 高 |
| 生产管理 | 缺少生产进度统计汇总 | 中 |
| 安装管理 | 缺少地图定位功能 | 低 |
| Dashboard | 统计数据来自前端计算而非后端API | 高 |

## 第一阶段：API 数据完善

### 1.1 后端新增统计接口

**文件**: `backend/src/controllers/statistics.controller.js`

新增接口：
- `GET /api/v1/statistics/area` - 获取面积统计（本月/本年）
- `GET /api/v1/statistics/flow` - 获取流程统计数据

### 1.2 前端对接

**文件**: `admin-web/src/pages/order/index.vue`

- 面积统计从 API 获取
- 添加导出按钮调用现有导出接口

## 技术要点

1. **API 扩展**：在现有 statistics.controller.js 中添加新方法
2. **批量操作**：使用 el-table 的 selection 功能 + 现有 API
3. **导出功能**：调用现有 `/api/v1/export/orders/excel` 接口
4. **数据刷新**：使用轮询或 WebSocket（已有 socket.io 依赖）
