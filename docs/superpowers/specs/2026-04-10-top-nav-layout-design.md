# 顶部导航布局重构设计文档

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将当前左侧导航布局重构为顶部导航 + 二级标签页 + 标签页多开的布局方案（方案 B）。

**架构：** 将 MainLayout.vue 从左侧侧边栏导航重构为顶部一级导航栏 + 左侧二级导航 + 标签页栏的三层布局。路由结构重新组织，按业务模块分组（订单、设计、生产、安装、统计、客户、设置）。标签页系统使用 Pinia store 管理，支持多开、关闭、右键菜单。

**技术栈：** Vue 3 Composition API, Pinia, Element Plus, Vue Router

---

## 现状分析

### 当前布局（MainLayout.vue）

- 左侧固定侧边栏（240px），可折叠
- 顶部面包屑 + 用户操作
- 菜单从路由自动生成

### 当前路由结构

- 12 个一级路由（dashboard, orders, review, design, production, install, archive, statistics, customers, settings）
- settings 下有 6 个子路由
- 详情/编辑页面标记为 hidden

## 设计方案

### 布局结构

```
┌─────────────────────────────────────────────────────────┐
│  顶部一级导航栏（深色背景，横向菜单）                      │
│  Logo | 订单 | 设计 | 生产 | 安装 | 统计 | 客户 | 设置  │
├─────────────────────────────────────────────────────────┤
│  左侧二级导航（浅色，可折叠，显示当前模块的子菜单）        │
│  或 顶部二级导航（扁平标签式筛选）                       │
├─────────────────────────────────────────────────────────┤
│  标签页栏（最近访问的页面，可关闭，可滚动）                │
├─────────────────────────────────────────────────────────┤
│  主内容区                                                │
│  ┌───────────────────────────────────────────────────┐  │
│  │ 搜索/筛选工具栏                                     │  │
│  │ 数据表格/内容                                      │  │
│  │ 分页                                              │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

### 模块分组

| 一级导航 | 图标 | 二级导航 | 角色限制 |
|----------|------|----------|----------|
| 订单 | Document | 全部订单, 待审核, 测量管理, 新建订单 | 无 |
| 设计 | Edit | 设计任务, 方案管理, 设计审核 | admin, designer, reviewer |
| 生产 | Setting | 生产任务, 物料管理, 物料核对 | admin, producer |
| 安装 | Position | 安装任务, 安装报告, 归档管理 | admin, installer |
| 统计 | DataAnalysis | 统计报表 | admin, reviewer |
| 客户 | User | 客户列表, 客户详情 | 无 |
| 设置 | Tools | 用户管理, 地区组织, 表单配置, 广告类型, 系统配置, 派单规则 | admin |

### 标签页系统

- 使用 Pinia store 管理标签页列表
- 每个标签页：{ path, title, name, closable }
- 点击导航时自动添加标签页（若不存在）
- 关闭标签页时自动跳转到最后一个标签页
- 右键菜单：关闭其他、关闭右侧、刷新
- 首页和登录页不可关闭

## 数据流

1. 用户点击顶部一级导航 → 切换当前模块 → 左侧显示该模块子菜单
2. 用户点击子菜单 → 路由跳转 → 标签页 store 添加/激活对应标签
3. 标签页栏渲染 store 中的标签列表
4. 用户点击标签 → 路由跳转
5. 用户关闭标签 → 从 store 移除 → 跳转到相邻标签

## 错误处理

- 无权限访问的模块：隐藏导航，直接访问时跳转 403
- 关闭最后一个标签页：自动跳转到前一个或首页
- 标签页过多（>20）：横向滚动，不限制数量
