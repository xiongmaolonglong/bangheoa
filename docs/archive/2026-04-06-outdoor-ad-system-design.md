# 户外广告测量安装派单系统设计规范

## 一、项目概述

### 1.1 项目背景

构建一套完整的户外广告测量安装派单管理系统，实现从申请测量到归档的全流程数字化管理。

### 1.2 核心流程

```
申请测量 → 审核 → 测量 → 审核 → 设计 → 审核 → 生产 → 核对 → 安装 → 审核 → 归档
```

### 1.3 系统组成

| 系统 | 使用对象 | 技术栈 |
|------|----------|--------|
| 微信小程序 | 客户 | 微信原生 |
| 管理后台 | 内部员工 | Vue 3 + Element Plus |
| 后端服务 | - | Node.js + Express |
| 数据库 | - | MySQL 8.0 |

### 3.3 审核机制

采用按角色分级审核机制，每个环节由对应角色的上级审核：
- 测量申请 → 审核主管审核
- 测量结果 → 审核主管审核
- 设计方案 → 审核主管审核
- 安装结果 → 审核主管审核

## 四、业务流程

### 4.1 订单状态流转

| 状态 | 说明 | 操作人 | 下一状态 |
|------|------|--------|----------|
| pending_review | 待审核（测量申请） | 客户提交 | measuring / rejected |
| measuring | 测量中 | 审核主管派单 | measure_review |
| measure_review | 待审核（测量结果） | 测量员提交 | designing / measuring |
| designing | 设计中 | 审核主管通过 | design_review |
| design_review | 待审核（设计方案） | 设计师提交 | producing / designing |
| producing | 生产中 | 审核主管通过 | checking |
| checking | 核对中 | 生产员提交 | installing / producing |
| installing | 安装中 | 核对员通过 | install_review |
| install_review | 待审核（安装结果） | 安装员提交 | archived / installing |
| archived | 已归档 | 审核主管通过 | - |
| rejected | 已驳回 | 审核主管驳回 | - |

## 六、派单规则

### 6.1 派单模式

支持三种派单模式：

| 模式 | 说明 |
|------|------|
| 自动派单 | 系统根据算法自动分配最优人选 |
| 人工派单 | 审核主管手动指定处理人 |
| 混合模式 | 系统推荐候选人，审核主管选择 |

### 6.2 自动派单算法

```
优先级评分 = 距离分(30%) + 工作量分(40%) + 技能分(30%)

距离分：订单位置与人员常驻位置的距离，越近分数越高
工作量分：当前待处理订单数，越少分数越高
技能分：人员技能标签与订单类型的匹配度
```

### 6.3 派单配置

- 按订单类型配置派单模式
- 设置各角色人员池
- 支持转派、改派操作

## 九、订单编号规则

```
[省份代码]-[分区代码]-[小组代码]-[年月]-[流水号]

```

### 9.2 编码规则

| 部分 | 长度 | 说明 | 示例 |

| 流水号 | 4位 | 当月该小组流水号 | 0001-9999 |

## 十四、API 接口设计

### 14.1 接口规范

- 基础路径：`/api/v1`
- 认证方式：JWT Token
- 响应格式：JSON

### 14.2 主要接口

#### 认证接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /auth/login | 登录 |
| POST | /auth/logout | 退出登录 |
| GET | /auth/profile | 获取当前用户信息 |

#### 订单接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /orders | 创建订单 |
| GET | /orders | 订单列表 |
| GET | /orders/:id | 订单详情 |
| PUT | /orders/:id | 更新订单 |
| GET | /orders/:id/logs | 订单日志 |

#### 审核接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /review/measure/:id | 审核测量申请 |
| POST | /review/measure-report/:id | 审核测量报告 |
| POST | /review/design/:id | 审核设计方案 |
| POST | /review/install/:id | 审核安装报告 |

#### 派单接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /dispatch/measure | 派单测量员 |
| POST | /dispatch/install | 派单安装员 |
| GET | /dispatch/recommend/:orderId | 获取推荐人选 |
