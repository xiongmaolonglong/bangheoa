# 户外广告派单系统 - 使用指南

## 快速开始

### 一键启动

**Windows**:
```bash
双击运行 start.bat
```

**Linux/Mac**:
```bash
chmod +x start.sh
./start.sh
```

### 手动启动

1. **启动后端**:
```bash
cd backend
npm install
npm run dev
```

2. **启动前端**:
```bash
cd admin-web
npm install
npm run dev
```

3. **访问系统**:
- 管理后台: http://localhost:5173
- API 文档: http://localhost:3000/api-docs

## 系统功能

### 1. 订单管理

#### 创建订单
1. 点击左侧菜单「订单管理」
2. 点击右上角「新建订单」
3. 填写客户信息、安装地址
4. 添加广告项目（广告类型、尺寸）
5. 提交保存

#### 订单状态流转
```
申请测量 → 待审核 → 测量中 → 测量待审 → 设计中 → 设计待审
→ 生产中 → 核对中 → 安装中 → 安装待审 → 已归档
```

#### 看板视图
1. 在订单列表页切换「看板」视图
2. 拖拽订单卡片变更状态
3. 点击订单卡片查看详情

---

### 2. 审核管理

#### 单个审核
1. 进入「审核中心」
2. 选择待审核订单
3. 填写审核意见
4. 选择「通过」或「驳回」
5. 通过时可指派下一步处理人

#### 批量审核
1. 在订单列表勾选多个订单
2. 点击「批量审核」按钮
3. 选择审核结果（通过/驳回）
4. 填写审核意见
5. 确认提交

---

### 3. 任务处理

#### 测量任务
1. 测量员登录查看「我的任务」
2. 选择订单进行测量
3. 填写测量数据（尺寸、材质、照片）
4. 提交测量报告

#### 设计任务
1. 设计师登录查看设计任务
2. 上传设计方案（CDR 文件）
3. 填写设计说明
4. 提交审核

#### 安装任务
1. 安装员登录查看安装任务
2. 现场安装并拍照
3. 填写安装报告
4. 提交审核

---

### 4. 数据统计

#### Dashboard 看板
- 今日待办任务
- 订单趋势图
- 状态分布饼图
- 效率指标
- 区域分布
- 超时预警

#### 统计报表
1. 进入「统计报表」
2. 选择时间范围
3. 查看各类统计图表
4. 导出报表数据

---

### 5. 系统设置

#### 用户管理
- 添加/编辑用户
- 分配角色权限
- 启用/禁用用户

#### 地区管理
- 省份管理
- 分区管理
- 小组管理

## 用户角色权限

| 角色 | 权限范围 |
|------|---------|
| admin | 系统管理员，全部权限 |
| reviewer | 审核主管，审核派单 |
| measurer | 测量员，测量作业 |
| designer | 设计师，方案设计 |
| producer | 生产员，生产管理 |
| checker | 核对员，物料核对 |
| installer | 安装员，安装作业 |

## 数据导出

### 导出订单列表
1. 在订单列表页点击「导出」
2. 选择导出字段
3. 选择导出格式（Excel/PDF）
4. 下载文件

### 批量导出
1. 勾选需要导出的订单
2. 点击「批量导出」
3. 选择导出格式
4. 下载文件

2. 查看通知列表

## API 接口

### 访问 API 文档
```
http://localhost:3000/api-docs
```

### 认证方式
```
Authorization: Bearer <token>
```

### 主要端点

| 端点 | 说明 |
|------|------|
| POST /api/v1/auth/login | 用户登录 |
| GET /api/v1/orders | 订单列表 |
| POST /api/v1/orders | 创建订单 |
| GET /api/v1/orders/:id | 订单详情 |
| PUT /api/v1/orders/:id | 更新订单 |
| POST /api/v1/review/:id/approve | 审核通过 |
| POST /api/v1/review/:id/reject | 审核驳回 |
| GET /api/v1/notifications | 通知列表 |
| GET /api/v1/statistics/dashboard | 仪表盘数据 |
| GET /api/v1/export/orders/excel | 导出订单 |

## 常见问题

### Q: 后端启动失败？
A: 检查数据库连接配置（backend/.env）

### Q: 前端无法访问 API？
A: 确认后端已启动，检查端口 3000 是否被占用

### Q: 登录失败？
A: 确认数据库中有 admin 用户，默认密码 admin123

### Q: 图片上传失败？
A: 检查 backend/uploads 目录是否存在且有写入权限
